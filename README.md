# SensorMood

Application Android développée en Java pour le Lab 21 : Capteurs embarqués Android.

## Objectif
Exploiter les capteurs d’un smartphone Android avec `SensorManager` et afficher les mesures en temps réel.

## Fonctionnalités
- Liste détaillée des capteurs disponibles
- Température, humidité et proximité avec graphe
- Champ magnétique avec visualisation dynamique
- Rotation mobile via gyroscope
- Boussole numérique
- Interface personnalisée rose/mauve
- Simulation automatique si certains capteurs sont absents sur l’émulateur

## Technologies
- Android Studio
- Java
- XML
- Navigation Drawer
- Fragments
- SensorManager
- MPAndroidChart

## Démo
L’application permet de naviguer entre plusieurs capteurs, d’afficher leurs valeurs et de visualiser leur évolution sous forme de courbes ou d’indicateurs numériques.
